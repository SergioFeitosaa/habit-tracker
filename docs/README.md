## Manter documentação e código sincronizados

Ao alterar um requisito, regra, comportamento ou configuração, atualize no mesmo PR os documentos impactados e a matriz de rastreabilidade. Indique como o comportamento foi validado e diferencie código implementado, teste automatizado e verificação manual pendente. Links para issues não substituem resultados de testes. Veja também [CONTRIBUTING.md](../CONTRIBUTING.md).
